# Kwork-pa

Ищет работу, которую Claude может сделать сам, в двух местах:

1. **Kwork**: парсит биржу проектов и оставляет заказы, которые Claude закроет сам:
   код, парсеры, боты, вёрстку, скрипты, таблицы, тексты, переводы, документы.
   Видео, дизайн, озвучку, звонки, офлайн и ведение рекламы отсеивает.
2. **2ГИС**: ищет местные компании, которым нужна помощь: у кого нет сайта, вместо сайта
   страница ВК или Taplink, сайт не открывается, нет мобильной версии или SEO.
   Для каждой компании предлагает, что ей продать (лендинг, бот записи, тексты).

Неэтичные заказы отсекаются сразу: накрутки, фейковые отзывы, спам, курсовые и дипломы
за студентов, обход капчи и защиты.

## Запуск из терминала

Нужен Python 3.10 или новее ([python.org](https://www.python.org/downloads/); на Windows при
установке отметьте «Add python.exe to PATH»). Скачайте проект (`git clone` или
Code → Download ZIP, затем распакуйте архив) и запустите лаунчер из папки проекта:

```bash
# Linux / macOS
./run.sh

# Windows: двойной клик по run.bat или в cmd / PowerShell
.\run.bat
```

При первом запуске лаунчер сам создаст окружение `.venv` и поставит зависимости.
Это займёт минуту. Если Python установлен под другим именем (например, в системе старый
`python3`, а рядом стоит `python3.12`), укажите его явно: `PYTHON=python3.12 ./run.sh`.
Потом откроется меню:

```
  1. Найти заказы на Kwork
  2. Следить за Kwork и показывать новые заказы
  3. Найти клиентов в 2ГИС
  4. Проверить текст задачи
  0. Выход
```

Меню задаёт пару вопросов и перед запуском показывает, какой командой сделать то же
самое без меню. Любую команду из этого README можно передать лаунчеру напрямую:

```bash
./run.sh kwork --min-price 3000 --llm      # Windows: .\run.bat kwork --min-price 3000 --llm
```

В примерах ниже вместо `python -m kwork_pa` пишите `./run.sh` (Windows: `.\run.bat`), если
пользуетесь лаунчером.

Ключи (2ГИС, Claude API, Telegram) лежат в файле `.env`: скопируйте `.env.example` в
`.env` и заполните. Ключ 2ГИС меню спросит само и предложит сохранить.

### Команда `kwork-pa`

Чтобы запускать без лаунчера, из любой папки, поставьте проект через
[pipx](https://pipx.pypa.io): он создаст для программы отдельное окружение и добавит
команду `kwork-pa` в PATH.

```bash
# один раз поставить pipx
sudo apt install pipx            # Debian/Ubuntu
brew install pipx                # macOS
py -m pip install --user pipx    # Windows
pipx ensurepath                  # Windows: py -m pipx ensurepath; затем откройте новый терминал

# из папки проекта
pipx install .
kwork-pa                         # меню
kwork-pa kwork --keyword парсер
```

`.env` и папка `results/` в этом случае берутся из текущей папки. Обычный `pip install .`
тоже работает, но только внутри активированного виртуального окружения: системный Python
в свежих Ubuntu, Debian и Homebrew не даёт ставить в него пакеты.

### Вручную

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m kwork_pa              # меню
python -m kwork_pa kwork --help # справка по команде
```

## Kwork

```bash
# все категории, 3 страницы, только подходящие для Claude
python -m kwork_pa kwork

# бюджет от 3000 ₽, не больше 15 откликов, поиск по слову
python -m kwork_pa kwork --min-price 3000 --max-offers 15 --keyword парсер

# конкретные категории: ID берите из адреса kwork.ru/projects?c=ID
python -m kwork_pa kwork --categories 11,5 --pages 5

# посмотреть и отсеянные заказы с причиной
python -m kwork_pa kwork --show-rejected

# следить за биржей каждые 5 минут и присылать новые заказы в Telegram
python -m kwork_pa kwork --watch 300 --telegram
```

Отчёт сохраняется в `results/kwork.csv` (открывается в Excel) и `results/kwork.md`.
Формат меняется флагом `--format csv,json,md`.

### Проверка через Claude API (`--llm`)

Правила (ключевые слова) работают бесплатно и мгновенно, но ошибаются на пограничных
заказах. С флагом `--llm` каждый отобранный заказ дополнительно читает Claude и
возвращает:

- берётся или нет, с уверенностью и оценкой объёма;
- что останется сделать человеку (доступы, запуск, сдача);
- риски и неясности в ТЗ;
- **черновик отклика** заказчику.

```bash
python -m kwork_pa kwork --llm --llm-limit 20
```

Нужен `ANTHROPIC_API_KEY`. По умолчанию модель `claude-opus-5-5` с низким уровнем
`effort` (для классификации этого хватает). Другую модель задаёт переменная
`CLAUDE_MODEL`. Если модель откажется отвечать, API сам повторит запрос на
рекомендуемой запасной модели (server-side fallback; работает для Opus 5.5, Opus 5,
Sonnet 5.5 и Fable 5.1).

### Если Kwork блокирует запросы

Парсер по очереди пробует AJAX-эндпоинт (JSON), JSON `window.stateData` на странице
и разбор HTML-карточек. Если сайт отвечает 403 или капчей:

- скопируйте заголовок `Cookie` из браузера (DevTools → Network) в `KWORK_COOKIE` в `.env`;
- или сохраните страницу `kwork.ru/projects` в браузере (Ctrl+S) и разберите файл:
  `python -m kwork_pa kwork --from-file projects.html`;
- если сайт поменял вёрстку, сохраните сырые ответы через `--dump kwork_dump` и пришлите
  их, чтобы поправить парсер.

Не уменьшайте `--delay` (по умолчанию 2 с между запросами): частые запросы быстрее
приводят к блокировке.

## 2ГИС: поиск клиентов

Работает через официальный Catalog API 2ГИС, сам сайт 2gis.ru не парсится. Ключ берётся
на [platform.2gis.ru](https://platform.2gis.ru), есть бесплатный демо-ключ (до 10
компаний на страницу).

```bash
# популярные ниши (автосервисы, салоны, стоматологии, кафе...) в Казани
python -m kwork_pa leads --city Казань

# свои ниши + проверка сайтов (HTTPS, мобильная версия, SEO, заглушки)
python -m kwork_pa leads --city "Нижний Новгород" --query "стоматология" --query "автосервис" --audit

# черновики персональных сообщений через Claude API
python -m kwork_pa leads --city Казань --query барбершоп --audit --pitch
```

Как считаются баллы:

| Признак | Баллы |
|---|---|
| Нет сайта и соцсетей | +50 |
| Нет сайта, только соцсети | +40 |
| Сайт не открывается, ошибка или заглушка | +40 |
| Вместо сайта соцсеть, конструктор или агрегатор | +30 |
| Нет мобильной версии | +20 |
| Нет HTTPS / ошибка SSL / Flash и фреймы | +15 |
| Сайт давно не обновлялся, почти нет текста | +10 |
| Нет title / meta description, медленная загрузка | +5 |
| Рейтинг ниже 4.0 (от 10 отзывов) | +5 |
| Сфера, где нужен бот записи / меню / калькулятор | +5 |
| Сеть от 3 филиалов / от 10 филиалов | −10 / −30 |
| В карточке нет контактов | −15 |

По умолчанию в отчёт попадают компании с баллом от 30 (`--min-score`). Отчёт сохраняется
в `results/leads.csv` и `results/leads.md`.

Пишите компаниям по одной и вручную. Массовые рассылки без согласия получателя
нарушают закон «О рекламе», а сбор и хранение контактов попадает под 152-ФЗ.

## Быстрая проверка текста задачи

```bash
python -m kwork_pa check "Написать Telegram-бота для записи в барбершоп"
# ПОДХОДИТ (балл 6)
# умеет: Чат-боты, Интеграции с мессенджерами
```

## Настройка фильтра

Правила лежат в `kwork_pa/capability.py`:

- `CAN_DO`: что Claude умеет (плюс к баллу);
- `CANNOT_DO`: что требует человека (минус к баллу);
- `FORBIDDEN`: что отсекается всегда.

Каждое правило задаётся набором регулярных выражений по основам слов и весом. Порог
прохождения задаёт `--min-score` (по умолчанию 3). Подсказки по рубрикам 2ГИС и
списки конструкторов и соцсетей лежат в `kwork_pa/leads.py`.
